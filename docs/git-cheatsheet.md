# Git Quick Reference

A small reference for common commands used while practicing.

```bash
# Check changed files
git status

# Stage a file
git add <file>

# Stage all changes
git add .

# Save staged changes
git commit -m "Describe the change"

# View recent commits
git log --oneline

# Download remote changes
git pull

# Upload local commits
git push
```

## Useful Habit

Run `git status` before committing. It helps verify exactly which files are about to be included.
