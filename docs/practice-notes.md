# Practice Notes

Use this file to keep short notes while experimenting with new concepts.

## Suggested Format

For each experiment, record:

- **Topic:** What is being practiced?
- **Goal:** What should the experiment demonstrate?
- **What I tried:** A short description of the approach.
- **What I learned:** The main takeaway.
- **Next step:** Something worth trying afterward.

Keeping brief notes makes it easier to revisit old experiments and see progress over time.
