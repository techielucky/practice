# Debugging Checklist

When a practice program does not behave as expected, work through these checks before changing large parts of the code.

1. Read the complete error message.
2. Identify the first relevant file and line number.
3. Check variable names, values, and data types.
4. Verify inputs and expected outputs.
5. Add temporary logging around the failing section.
6. Reduce the problem to the smallest reproducible example.
7. Change one thing at a time and test again.
8. Remove temporary debugging output after fixing the issue.

A systematic approach usually makes debugging faster and makes the underlying concept easier to understand.
