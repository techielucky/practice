# Practice

This folder is my personal learning, experimentation, and practice workspace.

The purpose of this folder is to practice different programming languages, technologies, concepts, tools, frameworks, and development techniques. The code stored here is primarily written while learning something new, testing an idea, solving a small problem, or experimenting with a particular concept.

This is not intended to be a collection of production-ready projects. Some files may be incomplete, some experiments may not work, and some implementations may be written only to understand how a particular concept works.

The main objective is learning through hands-on practice.

---

## About This Repository

Learning programming and technology requires more than just reading documentation or watching tutorials. A large part of the learning process comes from writing code, making mistakes, debugging problems, modifying existing implementations, and experimenting with different approaches.

This repository acts as a personal playground for that process.

I use this space to:

- Practice programming fundamentals
- Learn new programming languages
- Experiment with frameworks and libraries
- Test APIs
- Build small programs
- Try different algorithms
- Practice data structures
- Experiment with databases
- Learn backend development
- Practice frontend development
- Explore artificial intelligence and machine learning
- Work with embedded systems
- Practice electronics programming
- Test development tools
- Learn Git and GitHub
- Recreate small examples from documentation
- Implement concepts learned from courses and tutorials
- Build small proof-of-concepts
- Test ideas before turning them into proper projects
- Debug code and understand errors
- Compare different approaches to solving the same problem

- Bugs

- Poor optimization
- Repeated code
- Experimental code
- Temporary files

- Hardcoded values

- Inconsistent coding styles
- Deprecated approaches
- Code written specifically to test something
