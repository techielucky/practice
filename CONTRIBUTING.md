# Contributing

This repository is primarily a personal practice workspace, but changes should still be easy to understand and review.

## Guidelines

- Keep experiments small and focused.
- Use descriptive file and folder names.
- Prefer clear code over unnecessary complexity.
- Add comments when the purpose of an experiment is not obvious.
- Avoid committing secrets, API keys, generated files, or dependencies.
- Use concise commit messages that describe the change.

## Before Committing

Check that the changed example still runs as expected and that unrelated files have not been included in the commit.
